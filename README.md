# Atrium

B2B-площадка как **среда координации агентов**, не каталог с чат-ботом. Организации покупают и продают **партию**: объём, кратность упаковки, пол цены, склад, документы в одном контуре.

Агенты ищут партии и торгуются **в мандате**. По умолчанию человек входит только на **критическом** (крупная сумма, слабое доверие, спор) и всегда подписывает **деньги и товар**. Ужесточить или ослабить политику можно в кабинете — по важности партии и истории с контрагентом. Цену, кратность, резерв, допуск и рейтинг считает движок. Реплики пишет [Timeweb AI Gateway](https://api.timeweb.ai/v1); локальный [Ollama](http://127.0.0.1:11434) — запасной канал. Без обоих сценарий идёт на шаблонах, числа те же.

## Установка

Прототип крутится локально. Docker не нужен. Сделки живут в браузере (`localStorage`, ключ `atrium-marketplace-v5`).

| Слой | Зачем | Без него |
|---|---|---|
| Node 20+ и `npm install` | кабинеты, демо, движок цен | ничего не стартует |
| Timeweb AI Gateway | живые формулировки заявки и торга | запасной Ollama, иначе шаблоны |
| Ollama + модель | запасной голос, если шлюз молчит | шаблоны движка, числа те же |

### 1. Репозиторий и Node

Проверка: `node -v` (нужен 20 или новее). `npm` идёт вместе с Node.

```bash
git clone git@github.com:kobyzev-yuri/ai_mkt.git
cd ai_mkt
npm install
chmod +x start-demo.sh start-marketplace.sh
```

Сеть нужна на `npm install` и на живые реплики через Timeweb. Повторять установку при каждом запуске не надо — только после `git pull`, если менялся `package-lock.json`.

Если git снял бит исполнения у скриптов — снова `chmod +x start-demo.sh start-marketplace.sh`.

### 2. Timeweb — голос, не цены

Движок сам считает пол, потолок, кратность, статус и допуск. Модель только:

- дополняет разбор свободной фразы и **не затирает** уже найденные числа;
- переписывает реплики в комнатах.

Ключ AI Gateway: переменные `TIMEWEB_API_KEY` и `TIMEWEB_BASE_URL`, либо файл `~/keys/tw_sandkrit.txt` (строка 1 — `https://api.timeweb.ai/v1`, строка 2 — ключ). По умолчанию — GLM 4.7 FlashX, запасная — GPT-5.6 Luna. Thinking выключен, чтобы не держать крутилку.

Если шлюз недоступен — тот же запрос уходит в локальный Ollama (`qwen2.5:14b`). Если и его нет — работают `parse-need.ts` и шаблонные тексты. **`./start-demo.sh` LLM не вызывает**.

```bash
# запасной канал, необязательно
# Linux: https://ollama.com/download — или:
curl -fsSL https://ollama.com/install.sh | sh
ollama serve
ollama pull qwen2.5:14b
```

Модель Timeweb выбирают в шапке маркетплейса (кабинет офиса) или в `/office/settings`.

## Запуск

### Демо-прогон

Пять бизнес-процессов на одном экране. Выберите процесс в горизонтальном меню — «Далее» листает только его слайды (клик или → / пробел). Латунь — агент, терракота — человек.

1. **Загрузка витрины** — выгрузка 1С, отсев, подтверждение партий
2. **Поиск — торговля — сделка — остатки** — заявка, разбор, поиск, торг, подпись, резерв, списание
3. **Инцидент — обход** — факт человека, обход агента поставщика, акцепт заявителя (заказ идёт дальше)
4. **Срыв после аванса** — деньги уже в контуре: отклонение обхода → площадка расторгает, аванс к возврату, рейтинг
5. **Провал до аванса — откат** — срыв до оплаты, резерв снимается, рейтинг не трогаем

```bash
./start-demo.sh
```

Откройте [http://127.0.0.1:3001/demo](http://127.0.0.1:3001/demo). Без входа и без LLM. Кабинеты — другой процесс: `./start-marketplace.sh`.

### Маркетплейс

Живые роли. На старте — карточки входа с демо-паролями. Организация не выбирается в шапке: каждая карточка открывает свой кабинет.

```bash
./start-marketplace.sh
```

Откройте [http://127.0.0.1:3000/login](http://127.0.0.1:3000/login).

| Карточка | Пароль | Кабинет |
|---|---|---|
| Кофейня Холдинг / ТехСтрой | `1111` / `1112` | закупки: мандат, заявка, текущие, закрытые, аналитика |
| СеверПак / УралСталь | `2222` / `2223` | поставки: мандат, выгрузка 1С, партии, входящие, закрытые, аналитика |
| Atrium (владелец) | `0000` | бэкофис: правила, рельсы, арбитраж, номенклатура, участники |

| Раздел | Адрес | Кто |
|---|---|---|
| Вход | [`/login`](http://127.0.0.1:3000/login) | все роли |
| Закупки | [`/buy`](http://127.0.0.1:3000/buy) | закупщик: мандат, политика, заявки |
| Новая заявка | [`/rfq`](http://127.0.0.1:3000/rfq) | свободный текст → комнаты |
| Поставки | [`/sell`](http://127.0.0.1:3000/sell) | поставщик: выгрузка, партии, входящие |
| Сделки / заказы | [`/deals`](http://127.0.0.1:3000/deals), [`/orders`](http://127.0.0.1:3000/orders) | стороны своего контура |
| Бэкофис | [`/office`](http://127.0.0.1:3000/office) | владелец площадки |

По умолчанию агент торгует, человек — на критическом. Ужесточить («каждая сделка — подпись») или ослабить (автопилот) меняет **участник в кабинете**, не бэкофис — по важности партии и истории с контрагентом. Колокольчик в шапке — только срочное вмешательство.

## Контур сделки

Поиск свободных партий → досье контрагента → торг в мандате → допуск или подпись человека → счёт на аванс → резерв → комплект документов → приёмка → остаток.

Срыв — отдельная комната: факт человека → обход агента → акцепт или отклонение → иначе площадка. Рейтинг меняет только решение площадки. Схема: [`docs/GUIDE.md`](docs/GUIDE.md#6-схема-разрешения-инцидентов).

Каждый факт несёт свой обход. Откат есть не у всех — агент называет его сразу, решает человек, площадка применяет после отклонения.

| Факт | Когда | Обход агента (акцепт: заказ живой, рейтинг нет) | Откат после отклонения |
|---|---|---|---|
| Срыв отгрузки | в пути | зачёт в остаток + сдвиг срока | после аванса: деньги к возврату, рейтинг склада |
| Лот не подтвердился | комплектация / после аванса | дробим: что есть — сейчас, остаток со слота | до аванса: снять резерв; после: деньги к возврату |
| Недостача | приёмка | акт расхождения, зачёт, довоз | возврат груза, аванс к возврату |
| Качество | приёмка | замена партии или −8% в остаток | возврат партии, аванс к возврату |
| Накладная / УПД | приёмка | перевыпуск закрывающих за 1 день | отказ в приёмке, груз обратно |
| Просрочка оплаты | ждут аванс или остаток | пеня в остаток, резерв держим | только до аванса: снять резерв, рейтинг закупки. После приёмки отката нет |
| Форс-мажор | заказ живой, есть документ | срок +5 дн., рейтинг нет | откат без рейтинга (до аванса — резерв, после — деньги) |

Деньги и приёмка всегда за человеком. Сделку может пропустить допуск: малая партия, надёжный поставщик, оплаты клиента в срок, нет открытого спора. Иначе колокольчик.

Подробные условия: [`docs/GUIDE.md`](docs/GUIDE.md#протоколы-взаимодействия).

```
браузер → Next.js (:3000 кабинеты / :3001 демо)
              └─ движок сделок (TypeScript) — мандат, допуск, localStorage
```
