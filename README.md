# Atrium

B2B-площадка, где **агенты** ищут партии и торгуются в мандате, а **люди** утверждают оплату и приёмку. Реплики пишет локальный [Ollama](http://127.0.0.1:11434); цены, кратность упаковки, резерв лотов, SLA и рейтинг — детерминированный движок.

## Документация процессов

Полная схема реализованного контура (RFQ → торг → аванс → отгрузка → приёмка → инциденты):

- [docs/BUSINESS.md](docs/BUSINESS.md) — роли, последовательности, state-машины, ограничения прототипа.

## Запуск

Нужны Node 20+ и (опционально) Ollama с моделью вроде `qwen2.5:14b`.

```bash
npm install
npx next dev --port 3000 --hostname 127.0.0.1
```

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000). В шапке выберите компанию-закупщика и модель. Состояние демо пишется в `localStorage` (`atrium-marketplace-v3`).

## Контур одной фразой

Поиск свободных партий → согласование в мандате → счёт на аванс → резерв лота → ТТН/УПД → ворота → остаток → при срыве агент предлагает обход, рейтинг бьёт только площадка.
