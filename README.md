# Atrium

B2B-площадка как **среда координации агентов**, не каталог с чат-ботом. Организации покупают и продают **партию**: объём, кратность упаковки, пол цены, склад, документы в одном контуре.

Агенты ищут партии и торгуются **в мандате**. Человек задаёт политику (от пошагового контроля до автопилота) и подписывает **деньги и товар**. Цену, кратность, резерв, допуск и рейтинг считает движок. Локальный [Ollama](http://127.0.0.1:11434) только пишет реплики — без него сценарий идёт на шаблонах, числа те же.

## Два контура

Не смешивайте в одной вкладке: `localStorage` общий.

| Контур | Скрипт | npm | Открыть | Кэш Next |
|---|---|---|---|---|
| **Демо-прогон** | [`./start-demo.sh`](start-demo.sh) | `npm run demo` | [http://127.0.0.1:3001/demo](http://127.0.0.1:3001/demo) | `.next-demo` |
| **Маркетплейс** | [`./start-marketplace.sh`](start-marketplace.sh) | `npm run market` | [http://127.0.0.1:3000](http://127.0.0.1:3000) | `.next` |

Демо — отдельный процесс на порту **3001**, без входа и **без обращения к Ollama**. Кабинеты — порт **3000**. Страница `/demo` на `:3000` — тот же прогон внутри маркетплейса, не замена скрипта `:3001`.

Остановка: Ctrl+C в терминале скрипта.

## Установка

Прототип крутится локально. Docker, `.env` и облачные ключи не нужны. Сделки живут в браузере (`localStorage`, ключ `atrium-marketplace-v5`).

| Слой | Зачем | Без него |
|---|---|---|
| Node 20+ и `npm install` | кабинеты, демо, движок цен | ничего не стартует |
| Ollama + модель | живые формулировки заявки и торга | шаблоны движка, числа те же |

### 1. Репозиторий и Node

Проверка: `node -v` (нужен 20 или новее). `npm` идёт вместе с Node.

```bash
git clone git@github.com:kobyzev-yuri/ai_mkt.git
cd ai_mkt
npm install
chmod +x start-demo.sh start-marketplace.sh
```

Сеть нужна только на `npm install`. Повторять при каждом запуске не надо — только после `git pull`, если менялся `package-lock.json`.

Если git снял бит исполнения у скриптов — снова `chmod +x start-demo.sh start-marketplace.sh`.

### 2. Ollama — голос, не цены (необязательно)

Движок сам считает пол, потолок, кратность, статус и допуск. Ollama только:

- дополняет разбор свободной фразы и **не затирает** уже найденные числа;
- переписывает реплики в комнатах.

Если демона нет — работают `parse-need.ts` и шаблонные тексты. **`./start-demo.sh` Ollama не вызывает**: иначе запрос на `:11434` может поднять systemd-сокет даже без модели.

```bash
# Linux: https://ollama.com/download — или:
curl -fsSL https://ollama.com/install.sh | sh

ollama serve                 # если не поднялся как сервис; порт 11434
ollama pull qwen2.5:14b      # штатная модель
# мало RAM (~8 ГБ): ollama pull qwen2.5:7b
ollama list
```

Сервер должен отвечать на [http://127.0.0.1:11434](http://127.0.0.1:11434). Другой хост: `OLLAMA_HOST` (`src/lib/ollama.ts`). Модель выбирают в шапке маркетплейса или в `/office/settings`.

## Запуск

### Демо-прогон

Автопрогон закупка → исполнение → срыв, без ручной навигации по кабинетам.

```bash
./start-demo.sh
```

Откройте [http://127.0.0.1:3001/demo](http://127.0.0.1:3001/demo) → **«Запустить прогон»**. Есть камера поставщика (СеверПак): лид в комнате, не в мессенджере.

Что видно: разбор фразы → свободные партии → торг в мандате → подпись человека → аванс, резерв, накладная → претензия и обход без удара по рейтингу.

Для жюри этого экрана достаточно. Ollama не нужна.

### Маркетплейс

Живые роли. Организацию переключают в шапке, пароля нет.

```bash
./start-marketplace.sh
```

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000).

| Раздел | Адрес | Кто |
|---|---|---|
| Витрина | [`/`](http://127.0.0.1:3000/) | любой |
| Закупки | [`/buy`](http://127.0.0.1:3000/buy) | закупщик: мандат, политика, заявки |
| Новая заявка | [`/rfq`](http://127.0.0.1:3000/rfq) | свободный текст → комнаты |
| Поставки | [`/sell`](http://127.0.0.1:3000/sell) | поставщик: лиды, пропущено, витрина |
| Сделки / заказы | [`/deals`](http://127.0.0.1:3000/deals), [`/orders`](http://127.0.0.1:3000/orders) | стороны контура |
| Бэкофис | [`/office`](http://127.0.0.1:3000/office) | идеология, аналитика, настройки |
| Протоколы | [`/concept`](http://127.0.0.1:3000/concept) | условия допуска и колокольчика |
| Контроль | [`/trust`](http://127.0.0.1:3000/trust) | оценка агентов, журнал |

Политику торговли (пошагово / допуски / автопилот) меняет **участник в кабинете**, не бэкофис. Колокольчик в шапке — только срочное вмешательство.

## Контур сделки

Поиск свободных партий → досье контрагента → торг в мандате → допуск или подпись человека → счёт на аванс → резерв → комплект документов → приёмка → остаток. При срыве агент предлагает обход; рейтинг меняет только решение площадки.

Деньги и приёмка всегда за человеком. Сделку может пропустить допуск: малая партия, надёжный поставщик, оплаты клиента в срок, нет открытого спора. Иначе колокольчик.

Подробные условия: [`docs/GUIDE.md`](docs/GUIDE.md#протоколы-взаимодействия).

```
браузер → Next.js (:3000 кабинеты / :3001 демо)
              └─ движок сделок (TypeScript) — мандат, допуск, localStorage
```

## Что сознательно не подключено

Telegram, выгрузка 1С, ЭДО и проверка по ЕГРЮЛ на экранах подписаны **заглушка**: идея есть, канала нет. Сделка не должна уезжать в чат.

Не делаем в этом этапе: эквайринг, Диадок, боты, OData, микросервисы. Заморозка каналов — 28 октября, заявка — 31 октября.
