# Atrium на Langflow

Кабинеты закупки/поставки и движок мира остаются в Next.js. Здесь — **тот же граф ролей**, чтобы схема взаимодействия агентов читалась как поток Langflow.

Экран в прототипе: [http://127.0.0.1:3000/office/flow](http://127.0.0.1:3000/office/flow)

## Граф

```
Потребность → Оркестратор + Парсер → Поиск партий
                 ↓
        Агент закупки ⇄ Агент поставки
                 ↓
           Движок мандата  (числа, не LLM)
                 ↓
              Человек  →  Исполнение
                 ↓ срыв
            Инциденты → Человек | Арбитр
```

Агенты не вызывают друг друга как сервисы. Они публикуют **действие** в шину (`Data.trace`). Мандат принимает или отбрасывает числа. Модель реплик в этот граф не входит.

## Запуск Langflow

```bash
pip install langflow
LANGFLOW_COMPONENTS_PATH=/home/cnn/ai_mkt/langflow/components langflow run
```

В меню компонентов появится категория **atrium**: Оркестратор, Парсер, Поиск партий, Агент закупки, Агент поставки, Движок мандата, Человек, Исполнение, Инциденты, Арбитр.

Соберите цепочку слева направо, соединяя выход «Шина» / `Data` со входом следующего узла:

1. Оркестратор (текст потребности)  
2. Парсер  
3. Поиск партий  
4. Агент закупки → Агент поставки (или наоборот — оба читают шину)  
5. Движок мандата  
6. Человек (`Утвердить`)  
7. Исполнение  
8. Инциденты → Арбитр (если эскалация)

Playground покажет `trace`: кто какое действие опубликовал.

JSON графа: [`atrium-graph.json`](atrium-graph.json) и кнопка «Скачать граф JSON» на `/office/flow`.

Прогон шины без UI Langflow:

```bash
python langflow/run_bus.py
```
